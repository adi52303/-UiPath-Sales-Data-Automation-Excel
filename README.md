🧾 UiPath Sales Data Automation & Excel
This UiPath project automates the processing and visualization of sales data. It reads raw data from an Excel file, processes it to compute metrics like Total Sales, filters based on business rules, and generates automated Excel report — all without manual effort.

🚀 Features
Reads sales data from Excel

Calculates Total Sales (Quantity × Price)

Filters data by location, salesperson, and more

Summarizes and stores filtered data

Automatically generates Excel reports

Popup summary of key sales info

📌 How to Run
Clone or download this repository.

Open Main.xaml in UiPath Studio.

Make sure Sales_Data.xlsx is present in the correct path.

Run the process.

The bot will compute Total Sales, clean/filter the data, and generate Excel charts automatically.
